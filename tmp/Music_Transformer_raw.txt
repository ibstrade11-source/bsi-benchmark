Based on the provided abstract, here is a concise, factual analysis of the **Music Transformer** paper's main claims and contributions:

### **Core Problem Addressed**
* **Relative Timing in Music:** Music relies heavily on repetition and self-reference across various timescales. While Transformer models (using self-attention) excel at long-range coherence, music requires precise *relative timing*. 
* **Memory Bottleneck:** Existing relative positional self-attention mechanisms (e.g., Shaw et al., 2018) require quadratic memory complexity ($O(N^2)$) for intermediate relative information, making them computationally impractical for generating long musical sequences.

### **Main Contribution**
* **Memory-Efficient Relative Attention:** The authors propose a novel relative attention algorithm that reduces the intermediate memory footprint from **quadratic ($O(N^2)$) to linear ($O(N)$)** with respect to the sequence length. 

### **Key Claims & Capabilities**
* **Longer Generation Window:** The linear memory footprint allows the model to generate minute-long compositions (spanning thousands of steps), which is four times longer than previous baselines (e.g., Oore et al., 2018).
* **Structural Coherence:** The model can capture long-range musical structures, allowing it to:
  * Generate coherent continuations that elaborate on a specific motif.
  * Generate musical accompaniments conditioned on a given melody using a sequence-to-sequence (seq2seq) setup.

### **Evaluation and Results**
* The model was evaluated on two benchmark datasets: **JSB Chorales** and the **Piano-e-Competition**.
* The proposed Music Transformer achieved **state-of-the-art (SOTA) results** on the Piano-e-Competition dataset.
