## BSI Glossary — Judge Semantic Reference

The benchmark maintains an official terminology reference for interpreting
BSI-specific abbreviations and technical terms appearing in generated
analyses.

**Canonical benchmark glossary:**
`docs/BSI_GLOSSARY.md`

The glossary is a semantic-disambiguation resource only. It does not modify
the analytical criteria, scoring rules, provider behavior, RAW/BSI
comparison methodology, or judge-neutrality requirements.

The judge MUST NOT invent or guess the meaning of an undefined acronym or
technical term. If a term is absent from the glossary and is not defined
within the analysis itself or by an authoritative domain source, its meaning
must remain unresolved.

The glossary MUST NOT be interpreted as evidence that BSI terminology,
criteria, findings, or scores are correct, superior, or epistemically valid.

This architecture reference exists to reduce semantic ambiguity when compact
BSI analyses use domain-specific abbreviations such as BSI, EIG, ECC, REIG,
BIO, MAM, CORE_BEHMANESH, and other formally defined terms.

The glossary is therefore part of the benchmark's **interpretation layer**,
not part of the independent quality-scoring layer.
